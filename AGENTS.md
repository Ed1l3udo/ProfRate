# Instruções para agentes

- Este é um projeto educacional e de portfólio.
- Não copiar código do ProfRate acadêmico original.
- O foco principal de aprendizado é backend, banco de dados, APIs e testes.
- Antes de implementar decisões importantes do backend, explicar:
  - o problema;
  - as opções;
  - a escolha;
  - as consequências.
- Dividir mudanças em etapas pequenas e revisáveis.
- Não implementar grandes módulos de uma só vez.
- Não adicionar dependências sem explicar sua finalidade.
- Executar os testes relevantes após alterações.
- Não fazer commits automaticamente; o usuário revisará e fará os commits para aprender Git.
- No frontend e mobile, explicar pelo menos a integração com a API, mesmo quando a implementação for mais assistida.
- Ler README.md, docs/vision.md, docs/scope.md e docs/roadmap.md antes de propor mudanças arquiteturais.
- Nas áreas centrais de backend e banco, priorizar orientação e revisão do código escrito pelo usuário em vez de gerar a implementação inteira.
- Não consultar nem adicionar o repositório acadêmico original como dependência ou fonte de implementação.
